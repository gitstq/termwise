# TermWise

> Multi-LLM Terminal AI Coding Assistant

[![Python](https://img.shields.io/badge/Python-3.9+-blue.svg)](https://python.org)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

## Quick Start

```bash
pip install -r requirements.txt
termwise config  # Set up your API key
termwise chat    # Start interactive TUI
```

## Features

- Multi-LLM support (OpenAI, Anthropic, Ollama)
- Rich TUI interface with Textual
- File read/write tools
- Shell command execution
- Code search
- Cost tracking
- Theme switching

## Installation

```bash
pip install -e .
```

## Usage

```bash
termwise chat              # Interactive TUI mode
termwise ask "question"    # Quick ask mode
termwise config            # Configure API keys
termwise list-models       # List available models
termwise cost              # View cost statistics
```
